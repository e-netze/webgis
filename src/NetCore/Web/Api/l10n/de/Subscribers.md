## password: Passwort
## show-password: Passwort anzeigen
## capslock: Die Feststelltaste ist aktiviert
## captcha: Sicherheitscode
## captcha-hint: Bitte die Zeichen aus dem Bild eingeben
## captcha-reload: Neuen Code anzeigen
## captcha-reload-failed: Neuer Code konnte nicht geladen werden. Bitte die Seite neu laden.
## submit: Anmelden
## submitting: Anmeldung läuft...

## error: Fehler
### invalid-credentials: Benutzername oder Passwort ist falsch.

# mfa: Zwei-Faktor-Authentifizierung
## title: Zwei-Faktor-Authentifizierung
## verify-title: Bestätigungscode
## verify-hint: Bitte den 6-stelligen Code aus der Authenticator-App eingeben. Alternativ kann ein Wiederherstellungscode verwendet werden.
## verify-submit: Bestätigen
## setup-title: Zwei-Faktor-Authentifizierung einrichten
## enroll-required: Für dieses Konto ist die Zwei-Faktor-Authentifizierung verpflichtend. Bitte jetzt einrichten.
## setup-hint: Den QR-Code mit einer Authenticator-App (z.B. Microsoft Authenticator, Google Authenticator, FreeOTP) scannen und anschließend den angezeigten Code eingeben.
## setup-manual: Alternativ diesen Schlüssel manuell in der App eintragen:
## setup-submit: Aktivieren
## setup: Einrichten...
## code: Code aus der App
## code-or-recovery: Code aus der App oder Wiederherstellungscode
## status-enabled: Aktiviert
## status-disabled: Nicht aktiviert
## recommended: Empfehlung: Die Zwei-Faktor-Authentifizierung aktivieren, um das Konto zusätzlich zu schützen.
## required-hint: Die Zwei-Faktor-Authentifizierung ist für dieses Konto verpflichtend.
## not-available: Die Zwei-Faktor-Authentifizierung ist nicht verfügbar, weil die Subscriber-Datenbank noch nicht aktualisiert wurde. Ein Administrator muss das Datenbank-Setup (Setup) ausführen.
## recovery-title: Wiederherstellungscodes
## recovery-hint: Diese Codes jetzt sicher aufbewahren! Jeder Code kann einmal statt des App-Codes verwendet werden, falls das Gerät verloren geht. Die Codes werden nicht noch einmal angezeigt.

## recovery-continue: Weiter
## recovery-left: Verbleibende Wiederherstellungscodes: {0}
## regenerate: Neue Wiederherstellungscodes erzeugen
## disable: Zwei-Faktor-Authentifizierung deaktivieren
## disable-confirm: Zwei-Faktor-Authentifizierung wirklich deaktivieren?
## current-password: Aktuelles Passwort
## error: Fehler
### invalid-code: Der Code ist nicht korrekt. Bitte erneut versuchen.
### expired: Die Anmeldung ist abgelaufen. Bitte erneut anmelden.
### invalid-password: Das Passwort ist nicht korrekt.
### not-allowed: Diese Aktion ist nicht erlaubt.

# account: Konto
## title: Konto
## tile-description: Passwort ändern
## change-required-title: Neues Passwort erforderlich
## change-required-hint: Sie haben sich mit einem bekannten Standard-Passwort angemeldet. Bitte vergeben Sie jetzt ein neues Passwort, um die Anmeldung abzuschließen.
## change-password: Passwort ändern
## new-password: Neues Passwort
## new-password-repeat: Neues Passwort wiederholen
## password-rules: Mindestens {0} Zeichen, ohne Benutzername, Name oder E-Mail-Adresse, keine häufigen oder trivialen Passwörter (z.B. Sommer2026!, 123456...). Empfehlung: eine lange Passphrase.
## password-rules-classes: Zusätzlich mindestens {0} der Zeichenarten: Kleinbuchstaben, Großbuchstaben, Ziffern, Sonderzeichen.
## success: Erfolg
### password-changed: Das Passwort wurde geändert. Andere Sitzungen wurden abgemeldet.
## error: Fehler
### passwords-not-equal: Die neuen Passwörter stimmen nicht überein.
### invalid-length: Das neue Passwort muss mindestens {0} Zeichen lang sein.
### personal-info: Das neue Passwort darf weder Benutzernamen, Namen noch E-Mail-Adresse enthalten.
### too-common: Das neue Passwort ist zu häufig bzw. leicht zu erraten.
### too-simple: Das neue Passwort ist zu einfach (Wiederholungen oder Zeichenfolgen wie 1234/qwertz).
### character-classes: Das neue Passwort muss mindestens {0} der Zeichenarten enthalten: Kleinbuchstaben, Großbuchstaben, Ziffern, Sonderzeichen.
