# login: Anmelden
## title: Subscriber-Anmeldung
## username: Benutzername
## password: Passwort
## show-password: Passwort anzeigen
## capslock: Die Feststelltaste ist aktiviert
## captcha: Sicherheitscode
## captcha-hint: Bitte die Zeichen aus dem Bild eingeben
## captcha-reload: Neuen Code anzeigen
## captcha-reload-failed: Neuer Code konnte nicht geladen werden. Bitte die Seite neu laden.
## submit: Anmelden
## submitting: Anmeldung läuft...
## register: Als neuer Subscriber registrieren...
## error: Fehler
### invalid-credentials: Benutzername oder Passwort ist falsch.
### captcha-required: Bitte zusätzlich den Sicherheitscode eingeben.
### captcha-invalid: Der Sicherheitscode ist nicht korrekt oder abgelaufen. Bitte den neuen Code eingeben.
### too-many-attempts: Zu viele Anmeldeversuche. Bitte kurz warten und erneut versuchen.
### too-many-attempts-minutes: Zu viele fehlgeschlagene Anmeldeversuche. Die Anmeldung ist für ca. {0} Minute(n) gesperrt.
### login-failed: Die Anmeldung ist fehlgeschlagen. Bitte erneut versuchen.
